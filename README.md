# نظام إدارة الأقساط - كلية الهندسة / جامعة كلكامش
## Tuition Management System - Engineering College / Gilgamesh University

مشروع متكامل لإدارة ومتابعة أقساط طلبة كلية الهندسة مع دعم الاستيراد والتصدير عبر ملفات Excel والطباعة الرسمية.

---

## 🌟 مميزات النظام (Key Features)

1. **إدارة بيانات الطلبة والأقساط**:
   - تسجيل اسم الطالب الرباعي، القسم العلمي، المرحلة الدراسية، ونوع الدراسة (صباحي / مسائي).
   - تقسيم القسط السنوي إلى 4 دفعات مع توثيق رقم كل وصل مالي.
   - حساب تلقائي وفوري للمبالغ المسددة، المتبقية، ونسبة الإنجاز المالي.

2. **لوحة الإحصائيات الفورية**:
   - إجمالي عدد الطلبة المسجلين.
   - إجمالي المبالغ المطلوبة لجميع الطلبة بالدينار العراقي (IQD).
   - إجمالي المبالغ المسددة وإجمالي الديون المتبقية مع تنبيهات لونية واضحة.

3. **البحث والتصفية المتقدمة**:
   - بحث فوري وسريع بحسب اسم الطالب أو رقم أي وصل.
   - فلترة مخصصة حسب الأقسام العلمية، المراحل، ونوع الدراسة.
   - أزرار تصفية سريعة لنسبة السداد: (الكل، 25% فما فوق، 50% فما فوق، 75% فما فوق، 100% مسدد بالكامل، 0% غير مسدد).

4. **تكامل متقدم مع ملفات Excel**:
   - **قالب Excel**: تنزيل نموذج جاهز معبأ بأمثلة توضيحية.
   - **استيراد فوري**: رفع أي ملف Excel (.xlsx / .xls / .csv) وقراءة السجلات وإضافتها لقاعدة البيانات المحلية مباشرة.
   - **تصدير شامل**: تصدير كافة السجلات الحالية بملف Excel منظم ومعد للطباعة والتقارير.

5. **طباعة تقارير رسمية (Print-Ready)**:
   - تصميم ترويسة رسمية لجامعة كلكامش وكلية الهندسة مع التاريخ وعدد الطلبة.
   - إخفاء أدوات التحكم والأزرار والبحث تلقائياً أثناء الطباعة (`@media print`).

6. **أمان عالي وسرعة فائقة**:
   - حماية كاملة ضد هجمات حقن النصوص (XSS Protection) عبر تشفير المدخلات.
   - استبدال رسائل التنبيه الافتراضية بنوافذ تأكيد مخصصة (Custom Modal) وإشعارات منبثقة تفاعلية (Toast Notifications).
   - خادم محلي خفيف الوزن بدون أي حزم خارجية (Zero Dependencies).

## 🔥 ربط قاعدة البيانات Firebase (Firebase Setup)

البيانات تُحفظ في **Cloud Firestore** (مجموعة `students`) ويتطلب الدخول حساباً بالبريد وكلمة المرور.

1. أنشئ مشروعاً على [Firebase Console](https://console.firebase.google.com).
2. **Build > Authentication > Get started** ثم فعّل **Email/Password**، ومن تبويب **Users** أضف حسابات الموظفين.
3. **Build > Firestore Database > Create database** (اختر الموقع الأقرب، مثلاً `europe-west`).
4. من تبويب **Rules** الصق محتوى ملف `firestore.rules` ثم **Publish**.
5. **Project settings > General > Your apps > Web (`</>`)** سجّل تطبيق ويب وانسخ قيم `firebaseConfig` إلى ملف `firebase-config.js`.
6. شغّل المشروع (`npm start`) وسجّل الدخول.

**منع التكرار:** يُعتبر السجل مكرراً إذا تطابق (الاسم + القسم + المرحلة) بعد توحيد الإملاء (الهمزات، ى/ي، ة/ه، التشكيل، المسافات). يُستخدم هذا المفتاح كمعرّف للمستند، لذا ترفض قاعدة البيانات أي سجل مكرر حتى عند الرفع المتزامن من عدة مستخدمين. عند استيراد Excel تُضاف السجلات الجديدة فقط ويُعرض عدد المكرر الذي تم تجاهله.

## 🚀 طريقة تشغيل المشروع (How to Run)

### 1. عبر Node.js (الطريقة المفضلة):
داخل مجلد المشروع، قم بتشغيل الأمر التالي:
```bash
npm start
```
أو مباشرة:
```bash
node server.js
```
ثم افتح المتصفح على الرابط:
**[http://localhost:3000](http://localhost:3000)**

---

### 2. عبر Python (إذا لم تكن تريد استخدام Node):
```bash
python3 -m http.server 3000
```
ثم توجه إلى الرابط:
**[http://localhost:3000](http://localhost:3000)**

---

### 3. ملاحظة حول الفتح المباشر:
لا يعمل فتح `index.html` بالنقر المزدوج (`file://`) بعد ربط Firebase، لأن المتصفح يمنع تحميل الوحدات البرمجية من الملفات المحلية. استخدم إحدى الطريقتين أعلاه، أو انشر المشروع على **Firebase Hosting**.
